# 💵 نظام حاسبة الفئات النقدية وإدارة الصندوق (Cash Counter App)

تطبيق متكامل لحساب فئات العملات النقدية (الريال السعودي والعملات المعدنية) وإدارة ومطابقة الصندوق اليومي مع حماية البيانات والمزامنة الشبكية/السحابية.

---

## 🌟 الميزات الرئيسية

1. **حساب فوري لكافة الفئات النقدية:**
   - الفئات الورقية: 500, 200, 100, 50, 20, 10, 5, 1 ريال.
   - الفئات المعدنية: 2 ريال، نصف ريال (0.50)، ربع ريال (0.25).
   - أزرار سريعة لكل فئة: `+1`، `+5`، `+10`، و `+100` ورقة (رزمة كاملة).
   - مسح سريع لفئة محددة أو تصفير كامل.

2. **التفقيط المالي باللغة العربية:**
   - تحويل فوري وتلقائي للمبلغ الإجمالي إلى كلمات عربية صحيحة لغوياً (مثال: *"فقط خمسة آلاف وأربعمائة ريال سعودي لا غير"*).

3. **مطابقة الصندوق وكشف العجز والزيادة (Variance Reconciliation):**
   - مقارنة المبلغ الفعلي المحسوب مع المبيعات المتوقعة من نظام الكاشير.
   - تنبيهات ملونة وفورية: (✅ مطابق تماماً / 🟢 فائض نقدية / 🔴 عجز نقدية).

4. **حماية مشفرة للبيانات (Security & Data Protection):**
   - تسجيل دخول مشفر عبر رموز **JWT** مشفرة.
   - تشفير كلمات المرور والرمز السري عبر **Bcrypt**.
   - قاعدة بيانات محمية بتشفير **AES-256**.
   - **قفل الشاشة السريع (PIN Lock):** إمكانية قفل الشاشة برمز PIN فوراً لحماية أرقام الصندوق عند الابتعاد عن الجهاز، مع قفل تلقائي عند الخمول.

5. **سجل العمليات والتقارير:**
   - حفظ كامل لعمليات الجرد مع التاريخ، اسم الكاشير، الوردية، والفئات.
   - تصدير السجل إلى ملف **Excel (CSV)** يدعم اللغة العربية بترميز UTF-8 BOM.
   - طباعة إيصالات وتقارير جرد رسمية بحجم A4 أو طابعة الفواتير الحرارية مع أماكن للتوقيع.
   - تصدير واسترجاع نسخ احتياطية مشفرة (.enc).
